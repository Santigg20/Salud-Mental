# Salud mental

<p>
Algunos de los temas vistos
</p>

- Simplicidad y claridad
 Evita el exceso de elementos visuales, pop-ups invasivos o luces parpadeantes que generen fatiga visual o ansiedad

- Colores y tipografía suaves
 Utiliza paletas de tonos neutros, pastel o cálidos y tipografías legibles que transmitan calma en lugar de urgencia o estrés

- Espacio en blanco 
Deja suficientes áreas libres de texto o video para que la vista del usuario descanse
